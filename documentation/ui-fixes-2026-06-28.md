# UI fixes & polish — 2026-06-28

**Status:** Implemented (frontend only)
**Scope:** Contact page icons, About page hover/copy, DM unread badge, DM presence dot.

A batch of small UI fixes and polish on top of the new About / Contact pages and
the Personal Chats (DM) feature. All changes are frontend-only — no backend, no
API, no routing changes. Verified with `vite build` (clean), `npm test` (9/9
pass), and `eslint` on every touched file (clean).

---

## 1. Contact page — GitHub / LinkedIn icons (bug fix)

**Problem:** Navigating to `/contact` showed a broken/blank page. The lazy-loaded
Contact chunk crashed because `Contact.jsx` imported `Github` and `Linkedin` from
`lucide-react`, but the installed version (`^1.21.0`) dropped its brand icons —
those exports no longer exist, so the build failed with `MISSING_EXPORT`.

**Fix:** Replaced the two missing imports with small inline-SVG brand-mark
components (`Github`, `Linkedin`) defined at the top of `Contact.jsx`. They take
the same `size` prop and use `currentColor`, so they slot into
`<ContactCard icon={…} />` unchanged and keep the real brand marks + accent
colour. Only `Mail`, `Copy`, and `Check` are still imported from `lucide-react`.

| File | Change |
|------|--------|
| `Chat_app/src/pages/Contact.jsx` | Drop `Github`/`Linkedin` imports; add inline-SVG `Github`/`Linkedin` components. |
| `documentation/contact-us-page-2026-06-28.md` | Icons note updated. |

## 2. About page — hover animation on overview + FAQ

**Request:** The "The big **idea**." overview box and the FAQ items had no hover
animation (only the feature cards did).

**Change:** Added the same hover-lift used by the feature cards to
`.about-overview` and `.about-faq-item`: `transform: translateY(-4px)`, white
border, and the purple glow `0 18px 44px rgba(139,123,255,0.4)`, with a matching
`0.25s` transition. Reuses the existing token values — no new colours.

| File | Change |
|------|--------|
| `Chat_app/src/styles/about.css` | `.about-overview:hover` and `.about-faq-item:hover` rules + transitions. |

## 3. About page — overview copy + parse-error fix

**Change:** Updated the `OVERVIEW` copy (now "Connect Me…" branding). The new
text contained `you'll` inside a single-quoted JS string, which closed the string
early and caused a `Parsing error: Unexpected token ll`. Escaped the apostrophe
(`you\'ll`) — rendered output is unchanged.

| File | Change |
|------|--------|
| `Chat_app/src/pages/About.jsx` | New `OVERVIEW` string; escaped apostrophe. |

> Note: there is a missing space in the copy (`…right now.Connect Me…`) — left
> as-authored; flagged for the author to fix if desired.

## 4. Personal chat — unread badge is now black & white

**Request:** The unread-message badge in personal DMs showed in pink; make it
match the black-and-white theme.

**Change:** `.chat-dm-badge` no longer uses the purple→pink `--accent-grad`. It is
now a white pill with black text and a neutral shadow:

- background `var(--accent-grad)` → `#fff`
- colour `#fff` → `#000`
- shadow `rgba(139,123,255,0.45)` → `rgba(0,0,0,0.45)`

This is the only unread indicator (rendered in `ChatRoom.jsx` as
`<span className="chat-dm-badge">{c.unreadCount}</span>`).

| File | Change |
|------|--------|
| `Chat_app/src/styles/chat.css` | `.chat-dm-badge` recoloured to monochrome. |

## 5. Personal chat — presence dot static green, "In range now" removed

**Request:** The green blinking dot in the DM header should be solid green (not
blinking), and the "In range now" label should be removed.

**Change:**
- Added a scoped rule `.dm-peer-status .dot-live { box-shadow: none; animation: none; }`
  so the DM header dot is a static green indicator. Scoped to the DM header so the
  Rooms-screen live dot keeps its pulse.
- `statusText` for the `canSend` case is now an empty string (was `'In range now'`),
  so the header shows just the static green dot with no label. Out-of-range states
  ("…is away", "Out of range", etc.) are unchanged.

| File | Change |
|------|--------|
| `Chat_app/src/styles/chat.css` | `.dm-peer-status .dot-live` non-pulsing rule. |
| `Chat_app/src/components/DmPanel.jsx` | `canSend` `statusText` → `''`. |
